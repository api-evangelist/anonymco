# Anonym

> Anonym is a privacy-preserving advertising measurement and optimization platform, acquired by
> Mozilla in 2024 and now operated as a Mozilla product line. It sits between advertisers and
> large publisher platforms and runs attribution, measurement and campaign-optimization jobs
> inside a Trusted Execution Environment, combining encrypted advertiser and platform datasets
> without either side seeing the other's raw user-level data, and applying differential privacy to
> the outputs. Named platform partners include Reddit, Pinterest, Snap and TikTok.

## Agent-facing summary

Anonym publishes **no public API**. As of 2026-08-12 there is no developer portal, no API
reference, no OpenAPI/Swagger/GraphQL/AsyncAPI document, no MCP server, no A2A agent card, no SDK
in any public package registry, and no CLI. An agent cannot call Anonym, and there is nothing to
sign up for online.

What does exist:

- A **gated gRPC API host, `anonymapis.com`**, named by Anonym's own Transparency Portal — both in
  the portal's Content-Security-Policy `connect-src` allowlist and in the Angular environment block
  inside `https://anonymportal.com/main-FVGV5EV2.js` (`grpc: { host: "https://anonymapis.com" }`).
  It resolves in DNS to a Microsoft Azure address but refuses anonymous TCP connections on 443.
- A **customer-only Transparency Portal** at `https://anonymportal.com/`, an Angular single-page
  app authenticated through Firebase Authentication / Google Identity. Mozilla's own writeup
  describes portal sections for "API Integrations" and "Data Upload", plus a Knowledge Base — all
  behind the login.
- **Marketing and legal pages on mozilla.org.** `anonymco.com` no longer serves its own site; every
  path wildcard-redirects to `https://www.mozilla.org/en-US/anonym/`.

Onboarding is enterprise, human, and contractual. Mozilla's page describes integration as either
"fully integrated platform partners" who send encrypted data with no advertiser lift, or "simple,
secure tools or direct APIs" for advertisers moving data out of their cloud environment.
